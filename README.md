# Rommel Araneta — Resume Website

Professional single-page resume for Rommel Araneta  
BS Computer Engineering student · Production & Quality experience at Yazaki-Torres Manufacturing

## Contents

- `index.html` — full resume
- `styles.css` — responsive, accessible, print-ready styles
- `assets/avatar.svg` — placeholder avatar (replace with your photo)
- `assets/favicon.svg` — site icon

## How to view

**Easiest (Windows):**  
Double-click `index.html` — opens in your browser.

**With local server (optional):**
```powershell
cd path\to\resume-site
python -m http.server 8080
```
Then open http://localhost:8080

## Deploy (free)

1. Create a GitHub repository.
2. Upload these files.
3. Settings → Pages → Deploy from branch → main / root.
4. Site goes live at `https://yourusername.github.io/repo-name`.

## Customize later

- Replace `assets/avatar.svg` with a real square photo (JPG/PNG) and update the `src` in `index.html`.
- Add more projects, stronger metrics from Yazaki, or a GitHub link when ready.
- Change the accent color in `styles.css` (`--accent`).

Built with plain HTML & CSS. No build step required.
